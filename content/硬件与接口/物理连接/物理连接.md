# 物理连接

EtherCAT 数据必须先通过实际链路到达 ESC，才谈得上寻址、配置和过程数据交换。常见连接方式有通过 PHY 的以太网端口，以及用于模块间短距离连接的 EBUS。

## MAC、MII、PHY 与网线

以使用外部 PHY 的 100BASE-TX 接口为例：

```text
主站 MAC ↔ MII ↔ PHY ↔ 隔离变压器 / RJ45
                                ↕ 网线
从站 ESC ↔ MII ↔ PHY ↔ 隔离变压器 / RJ45
```

MAC 处理以太网链路层收发。Ethernet 头通常由驱动提供在发送缓冲区中，MAC 按其能力完成帧发送、FCS 生成或检查等工作；不能把它理解为自动把任意 CPU 数据转换成完整应用协议。

**MII（Media Independent Interface）** 是 MAC/ESC 与 PHY 之间的数字接口。发送方向有数据和发送使能，接收方向有数据、数据有效、错误和接收时钟等信号。PHY 管理接口用于访问 PHY 的控制和状态，链路状态还可以通过专用信号提供，具体连线取决于芯片。

**PHY** 把内部数字数据转换为适合线路传输的信号，并在接收端恢复数据。隔离变压器通过磁耦合传递信号并提供电气隔离；RJ45 是连接器。100BASE-TX 使用两对双绞线承担收发，不能把这一用线方式推广到所有以太网速率。

对端 PHY 按各自配置建立符合要求的链路后，向 ESC 报告 Link 状态。Link up 表示物理链路可用，不表示从站已进入 OP，二者区别见[AL 状态机](../../配置与运行/AL状态机/AL状态机.md)。

## 缓冲与时钟

接收侧恢复出的时钟与 ESC 内部处理时钟不一定完全相同，因此需要缓冲协调时钟差异。FIFO 是按先入先出顺序保存数据的缓冲，不等于必须先收完整帧再转发。

低延迟硬件会尽量减少转发等待，因此 ESC 与 PHY 的时钟关系、接口时序和 PHY 选型很重要。具体 FIFO 结构和时钟连接属于芯片实现，不能仅由“有无 FIFO”判断是否采用整帧存储转发。

## EBUS

EBUS 是另一种 EtherCAT 物理连接方式，可以通过 ESC 的低压差分接口连接相邻模块，而不使用外接普通 Ethernet PHY：

```text
以太网端口：ESC ↔ MII ↔ PHY ↔ 网线
EBUS 端口： ESC ↔ LVDS 差分连接 ↔ ESC
```

它常用于设备内部或相邻 IO 模块间的短距离连接。差分线需要匹配终端以控制反射，实际布线、终端电阻和传输距离应对应器件及连接设计。

## 端口、回环与分支

ET1100 最多有 Port 0～3，每个通信端口具有收发方向。ESC 内部按规定路径转发，链路末端或关闭端口通过内部回环使帧走返回路径。

以从 Port 0 进入的 ET1100 路径为例，可按 `Port 0 → EPU → Port 3 → Port 1 → Port 2 → Port 0` 理解端口处理次序；某个端口的外部支路会先被遍历并返回，再继续后续端口。

因此，线型网络不需要额外拉一根从末端回到主站的网线，也可以形成帧的逻辑返回路径。树形网络中，一条支路遍历完成后再继续另一条支路，实际访问次序由端口连接和内部转发顺序决定。

这个次序关系到启动时按位置找从站，也关系到[DC 时钟](../../时钟同步/DC时钟/DC时钟.md)的传播延迟测量。
