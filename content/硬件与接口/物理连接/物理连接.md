# 物理连接

连接方式有通过 PHY 的以太网端口，以及用于模块间短距离连接的 EBUS。

## MAC、MII、PHY 与网线

以使用外部 PHY 的 100BASE-TX 接口为例：

```text
主站 MAC ↔ MII ↔ PHY ↔ 隔离变压器 ↔ RJ45
                                    ↕ 网线
从站 ESC ↔ MII ↔ PHY ↔ 隔离变压器 ↔ RJ45
```

**MII（Media Independent Interface）** 是 MAC/ESC 与 PHY 之间的数字接口。
发送方向有数据和发送使能，
接收方向有数据、数据有效、错误和接收时钟等信号。
PHY 管理接口用于访问 PHY 的控制和状态，链路状态还可以通过专用信号提供。

**PHY** 把内部数字数据转换为适合线路传输的信号，并在接收端恢复数据。
隔离变压器通过磁耦合传递信号并提供电气隔离。
RJ45 是连接器。
100BASE-TX 使用 两对双绞线 承担收发，不能把这一用线方式推广到所有以太网速率。

对端 PHY 按各自配置建立符合要求的链路后，向 ESC 报告 Link 状态。
Link up 表示物理链路可用，不表示从站已进入 OP，二者区别见[AL 状态机](../../配置与运行/AL状态机/AL状态机.md)。

## 缓冲与时钟

接收侧恢复出的时钟 与 ESC 内部处理时钟，不一定完全相同，因此需要 缓冲 协调时钟差异。
FIFO 是按 先入先出 顺序，保存数据的缓冲，不等于必须先收完 整帧 再转发。

低延迟硬件会尽量减少 转发等待。
具体 FIFO 结构和时钟连接 属于芯片实现，不能仅由“有无 FIFO”判断 是否采用 整帧存储转发。

## EBUS

EBUS 是另一种 EtherCAT 物理连接方式，可以通过 ESC 的 低压差分接口 连接相邻模块，而不使用外接普通 Ethernet PHY：

```text
以太网端口：ESC ↔ MII ↔ PHY ↔ 网线
EBUS 端口： ESC ↔ LVDS 差分连接 ↔ ESC
```

它常用于 设备内部或相邻 IO 模块间 的短距离连接。
差分线需要匹配 终端 以控制反射，实际布线、终端电阻和传输距离应对应器件及连接设计。

## 端口、回环与分支

ET1100 最多有 Port 0～3，每个通信端口具有收发方向。
ESC 内部按规定路径转发，链路末端或关闭端口 通过 内部回环 使帧走返回路径。

以从 Port 0 进入的 ET1100 路径为例，
可按 `Port 0 → EPU → Port 3 → Port 1 → Port 2 → Port 0` 理解端口处理次序，
某个端口的外部支路会先被 遍历并返回，再继续后续端口。

线型网络：
不需要额外拉一根从末端回到主站的网线，也可以形成帧的逻辑返回路径。
树形网络：
一条支路遍历完成后再继续另一条支路，实际访问次序由端口连接和内部转发顺序决定。

这个次序关系到启动时按位置找从站，也关系到[DC 时钟](../../时钟同步/DC时钟/DC时钟.md)的传播延迟测量。
