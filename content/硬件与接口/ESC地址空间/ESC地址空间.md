# ESC 地址空间

主站 和 MCU 要访问 ESC 的状态、配置和数据。
读写某个地址，就是读取状态、设置功能或交换数据。

## 地址范围不等于 RAM 容量

ESC 内部使用 16 位字节地址，最多表示 64 KB 地址空间：

| 地址范围 | 用途 |
| --- | --- |
| `0x0000～0x0FFF` | ESC 寄存器地址区 |
| `0x1000～0xFFFF` | 可用于过程数据等 RAM 的地址范围，实际实现容量由 ESC 决定 |

ET1100 有 8 KB 过程数据 RAM，对应从 `0x1000` 开始的实际数据区。
不能因为地址可以写到 `0xFFFF`，就认为所有地址都有 RAM。
寄存器区也并非每个地址，都实现了可自由读写的寄存器。

## 寄存器有固定含义

寄存器是映射到特定地址、具有规定功能和访问权限的硬件资源。

| 起始地址或区域                    | 主要功能                                |
| -------------------------- | ----------------------------------- |
| `0x0000` 附近                | ESC 类型、功能和资源数量                      |
| `0x0010`、`0x0012`          | 配置站地址、配置站别名                         |
| `0x0100` 附近                | 数据链路控制和状态                           |
| `0x0120`、`0x0130`、`0x0134` | AL Control、AL Status、AL Status Code |
| `0x0140` 附近                | PDI 和 ESC 配置                        |
| `0x0200` 附近                | 事件请求与屏蔽                             |
| `0x0300` 附近                | 接收错误等计数                             |
| `0x0400` 附近                | 看门狗                                 |
| `0x0500` 附近                | EEPROM 接口控制                         |
| `0x0600` 起                 | FMMU 配置                             |
| `0x0800` 起                 | SyncManager 配置                      |
| `0x0900` 起                 | 分布式时钟、同步与锁存                         |

## 先读能力，再决定访问长度

| 地址 | 长度 | 内容 |
| --- | --- | --- |
| `0x0000` | 1 B | ESC类型，例如ET1100=`0x11`、ET1200=`0x12`；IP Core类型常见`0x04/0x05` |
| `0x0001` | 1 B | Revision |
| `0x0002` | 2 B | Build |
| `0x0004` | 1 B | FMMU通道数 |
| `0x0005` | 1 B | SM通道数 |
| `0x0006` | 1 B | 过程数据RAM容量，单位KiB |
| `0x0007` | 1 B | 各端口类型描述 |
| `0x0008～0x0009` | 2 B | 功能支持位；bit2为DC支持，bit3为DC位宽（1为64位） |

ET1100有8个FMMU、8个SM、8 KiB RAM；笔记中的另一台ESC读出3、4、4，这不能用ET1100的资源数覆盖解释。每个FMMU配置块16 B，每个SM配置块8 B，所以清3个FMMU是48 B，清4个SM是32 B。

端口描述或时间寄存器有四个端口字段，不表示板上一定有四个实际网口。芯片可用功能、版本和板级引脚都要核对。

## 字节地址、位号和软件掩码

`0x0502`开始的Control/Status是16位寄存器，其中bit15实际落在字节`0x0503`的bit7。若程序从`0x0500`读取32位小端值，则该状态字位于高16位，Busy掩码变为`0x80000000`；若只从`0x0502`读16位，Busy掩码为`0x8000`。

同理，从`0x0004`读32位时，SM数量位于bit15:8，RAM容量位于bit23:16；它们不因此变成单个硬件寄存器内部的固定位域。宏名或十六进制掩码必须连同读取起点、宽度、字节序解释。

连续写入覆盖某字段，不表示每个字节均可写。状态位和只读位由硬件维护，保留位写0，未实现的寄存器不能随意访问。细节应回到相应功能页，不能把整个寄存器区当成普通RAM。

## DPRAM：网络和本地应用交换数据

**DPRAM（Dual-Port RAM，双端口 RAM）** 可以从 EtherCAT 网络侧和 PDI 本地侧访问。
这里的“双端口”指内存访问侧，与 ESC 有几个外部通信端口不是同一个概念。

```text
目标位置：主站 → EtherCAT 写访问 → DPRAM → PDI 读访问 → MCU
实际位置：MCU  → PDI 写访问      → DPRAM → EtherCAT 读访问 → 主站
```

邮箱和过程数据可以占用不同的 RAM 区域。
RAM 提供存储，[SyncManager](../../通信机制/SyncManager/基本原理/基本原理.md)管理双方访问，防止读到一半新、一半旧的数据。

## 区分三种地址

| 地址       | 表示什么                              |
| -------- | --------------------------------- |
| 配置站地址    | 网络中的哪台从站                          |
| ESC 内部地址 | 该从站内部哪个 寄存器或 RAM 字节               |
| 逻辑地址     | 主站统一 过程映像 中的哪个位置，由 FMMU 映射到各站内部地址 |

EEPROM 配置表经常按 **16 位字地址** 编号，而 ESC 寄存器按 **字节地址** 编号。
比较两张表时要先确认单位，见[SII 与 ESI](../../配置与运行/设备描述/SII与ESI/SII与ESI.md)。
