# ESC 地址空间

主站和 MCU 要访问 ESC 的状态、配置和数据，ESC 因而把这些资源组织成有地址的空间。读写某个地址，就是读取状态、设置功能或交换数据。

## 地址范围不等于 RAM 容量

ESC 内部使用 16 位字节地址，最多表示 64 KB 地址空间：

| 地址范围 | 用途 |
| --- | --- |
| `0x0000～0x0FFF` | ESC 寄存器地址区 |
| `0x1000～0xFFFF` | 可用于过程数据等 RAM 的地址范围，实际实现容量由 ESC 决定 |

ET1100 有 8 KB 过程数据 RAM，对应从 `0x1000` 开始的实际数据区。不能因为地址可以写到 `0xFFFF`，就认为所有地址都有 RAM；寄存器区也并非每个地址都实现了可自由读写的寄存器。

## 寄存器有固定含义

寄存器是映射到特定地址、具有规定功能和访问权限的硬件资源。例如读取 `0x0130` 可以获得 AL Status，读取 `0x0300` 起的区域可以获得接收错误计数。某些寄存器具有只读、读后清除或写入触发动作等特性，不能按普通 RAM 理解。

| 起始地址或区域 | 主要功能 |
| --- | --- |
| `0x0000` 附近 | ESC 类型、功能和资源数量 |
| `0x0010`、`0x0012` | 配置站地址、配置站别名 |
| `0x0100` 附近 | 数据链路控制和状态 |
| `0x0120`、`0x0130`、`0x0134` | AL Control、AL Status、AL Status Code |
| `0x0140` 附近 | PDI 和 ESC 配置 |
| `0x0200` 附近 | 事件请求与屏蔽 |
| `0x0300` 附近 | 接收错误等计数 |
| `0x0400` 附近 | 看门狗 |
| `0x0500` 附近 | EEPROM 接口控制 |
| `0x0600` 起 | FMMU 配置 |
| `0x0800` 起 | SyncManager 配置 |
| `0x0900` 起 | 分布式时钟、同步与锁存 |

这张表用于按功能定位，具体长度和访问效果由对应寄存器定义决定。

## DPRAM：网络和本地应用交换数据

**DPRAM（Dual-Port RAM，双端口 RAM）** 可以从 EtherCAT 网络侧和 PDI 本地侧访问。这里的“双端口”指内存访问侧，与 ESC 有几个外部通信端口不是同一个概念。

```text
目标位置：主站 → EtherCAT 写访问 → DPRAM → PDI 读访问 → MCU
实际位置：MCU  → PDI 写访问      → DPRAM → EtherCAT 读访问 → 主站
```

邮箱和过程数据可以占用不同的 RAM 区域。RAM 提供存储，[SyncManager](../../通信机制/SyncManager/SyncManager.md)管理双方访问，防止读到一半新、一半旧的数据。

## 区分三种地址

| 地址 | 表示什么 |
| --- | --- |
| 配置站地址 | 网络中的哪台从站 |
| ESC 内部地址 | 该从站内部哪个寄存器或 RAM 字节 |
| 逻辑地址 | 主站统一过程映像中的哪个位置，由 FMMU 映射到各站内部地址 |

此外，EEPROM 配置表经常按 **16 位字地址** 编号，而 ESC 寄存器按 **字节地址** 编号。比较两张表时要先确认单位，见[设备描述](../../配置与运行/设备描述/设备描述.md)。
