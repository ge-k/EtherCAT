# 指示灯

RUN、ERR和链路灯提供快速观察入口，但灯名必须结合设备手册和接线解释。某设备的 PWR、SF 或厂家自定义 RUN，不能未经确认就套用 ESC 的标准状态表。

## RUN 与 AL 状态

按 EtherCAT RUN指示规则，绿色RUN灯表示[AL状态](../../配置与运行/AL状态机/AL状态机.md)：

| 灯态 | 状态 |
| --- | --- |
| 灭 | INIT |
| 慢闪 Blinking | PRE-OP |
| 单闪后停顿 Single Flash | SAFE-OP |
| 常亮 | OP |
| 快闪 Flickering | BOOT；部分ESC也用于SII加载过程 |

“单闪”与持续慢闪不同。即使RUN显示OP，也不证明实际GPIO翻转、电机使能或应用功能全部正常。

## ERR 的来源

ERR可能由ESC直接驱动，也可能由MCU按应用错误驱动。对具备相应自动指示能力的ESC，常见含义包括：灭为无错误，快闪为SII加载错误，慢闪为无效硬件配置，单闪为AL错误标志，双闪为过程数据看门狗超时，常亮可指PDI看门狗等应用控制器故障。具体支持哪些灯态、错误优先级和软件是否覆盖，须查对应实现。

故障定位应同时读取AL Status/Code、[看门狗](../看门狗/看门狗.md)和链路诊断。一次断电重启恢复，仅是现象，不足以确定根因或形成通用处理办法。

## 支持 LED Override 的 ESC

部分ESC提供 `0x0138` RUN LED Override、`0x0139` ERR LED Override，**ET1100不支持这两个寄存器**。

在支持的实现中，bit4开启覆盖，bit3:0选择灯态：`0`灭、`1～C`闪1～12次、`D`慢闪、`E`快闪、`F`常亮。这是预定义编码，不是任意自定义波形。

RUN覆盖会被后续有效AL状态变化取消；ERR覆盖会被新的自动错误条件取消。读值反映当前LED输出。该功能可用于识别设备，也不能替代读取实际状态。
