# 系统组成

EtherCAT 是面向工业控制的实时通信技术。
一个系统通常由一个主站和多个从站组成：
主站组织通信、发送控制数据并收集反馈；
从站可以是远程 IO、伺服驱动器、变频器、步进驱动器或分支设备。

## 主站、ESC 与应用各做什么

主站由主站软件及其使用的以太网通信硬件共同构成。
网卡或以太网控制器负责帧的收发，
主站软件负责发现设备、配置通信、安排周期和处理状态。

从站中的 **ESC（EtherCAT Slave Controller，从站控制器）** 负责高速通信。
对于带 MCU 的典型从站，可以这样理解数据路径：

```text
主站软件 → 主站网口 → EtherCAT 链路
                            ↓
                     从站 PHY → ESC
                                 ↕ PDI
                                MCU → IO / 电机控制
```

PHY 是物理层收发器，负责网线上的信号；
PDI 是本地应用访问 ESC 的接口。这些接口的具体作用见[物理连接](../../硬件与接口/物理连接/物理连接.md)和[PDI](../../硬件与接口/PDI/PDI.md)。

ESC 在帧经过时完成地址判断、数据读写、**工作计数器更新和转发**，
MCU 主要运行从站应用、上层通信协议和设备控制算法。
简单数字 IO 从站也可以直接使用 ESC 的数字 IO 接口，不一定需要 MCU。

这种分工使网络转发不必等待 MCU 处理；

## ESC 内部几种机制怎样配合

| 机制          | 主要解决的问题             |
| ----------- | ------------------- |
| 端口与 EPU     | 帧从哪里经过，哪些命令 需要本从站处理 |
| 寄存器与 DPRAM  | 控制信息、状态和交换数据 存在哪里   |
| FMMU        | 怎样把网络上的逻辑地址映射到本从站地址 |
| SyncManager | 网络侧和本地应用，怎样交换一致的数据  |
| DC          | 不同从站怎样使用共同的时间基准     |
| AL 状态机      | 当前允许使用哪些通信功能        |

**EPU（EtherCAT Processing Unit）** 是 ESC 内部处理 EtherCAT Datagram 的硬件模块。Datagram 是帧中的一条访问命令，结构见[帧与子报文](../../通信机制/帧与子报文/帧与子报文.md)。

## ET1100 是一种具体 ESC

ESC 是器件类别，Beckhoff ET1100 是其中一个型号。
ET1100 的主要资源包括：
最多 4 个通信端口、8 个 FMMU、8 个 SyncManager、8 KB 过程数据 RAM 和 64 位分布式时钟，以及数字 IO、SPI、并行微控制器等 PDI 选择。

ET1100 的这些数量和接口能力不能直接套到其他 ESC。
系统原理可以共用，资源分配和硬件设置则要对应具体芯片。
