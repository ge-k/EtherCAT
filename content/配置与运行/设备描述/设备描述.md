# 设备描述

主站要正确配置一台从站，需要知道 设备身份、通信能力、数据布局、同步方式。

## EEPROM、SII 与 ESI

| 名称                              | 作用                                         |
| ------------------------------- | ------------------------------------------ |
| EEPROM                          | 从站上的非易失存储器，保存掉电后仍保留的数据                     |
| SII：Slave Information Interface | 从站侧，常存放在 EEPROM 中，<br>本从站设备自己报告什么身份和基本通信信息 |
| ESI：EtherCAT Slave Information  | 主站工程工具侧的 XML 文件，<br>这个型号有哪些能力、默认值和配置选择     |

**工程配置**：

```
本工程实际用了哪几台设备
它们怎样连接
每台选择了哪个 PDO 组合
哪些 PLC 变量对应哪些 PDO 数据
总线周期是多少
选择哪种 DC 模式
启动时需要设置哪些参数
```

**已经接好设备，但还没有建立工程**：
```
主站实际发送 EtherCAT 报文
    ↓
发现从站，读取端口状态等信息，确定实际连接关系
    ↓
通过 ESC 的 EEPROM 访问接口读取 SII
    ↓
取得 Vendor ID、Product Code、Revision 等身份信息
    ↓
在本机已有的 ESI 文件中查找匹配的设备描述
    ↓
找到后，知道应当把它显示成哪个产品、提供哪些 PDO 和同步模式供配置
    ↓
根据扫描结果建立工程中的设备列表
```

**先建立工程，再连接设备:**

```
导入厂家 ESI
    ↓
从设备目录选择伺服、IO 等产品
    ↓
在工程中安排预期连接顺序和分支
    ↓
选择各设备的 PDO、关联程序变量、选择同步模式
    ↓
保存工程
【到这里是离线配置，不需要实际设备】

    ↓
按工程接好真实设备，连接主站
    ↓
在线扫描，读取实际设备的 SII 身份和端口等信息
    ↓
核对实际设备 与 工程预期：
数量、连接关系、厂商、产品代码、修订是否符合要求
    ↓
匹配后，主站按工程配置设备
    ↓
检查配置和AL状态迁移结果，进入运行
```

两者的区别是：**工程里的设备列表，是先手工建立，还是先扫描真实设备再建立。**

## ESI 包含哪些信息

| 内容             | 具体包含什么                                 | 工程工具用来做什么                |
| -------------- | -------------------------------------- | ------------------------ |
| 厂商信息           | Vendor ID、厂商名称及相关显示信息                  | 建立设备目录、匹配厂商              |
| 产品身份           | Product Code、Revision、设备类型名称等          | 区分产品和相应修订                |
| 界面显示信息         | 产品名称、分组、图标、说明等                         | 在设备选择界面中展示               |
| 设备与端口信息        | 物理端口形式、设备结构及有关特性                       | 描述可连接的设备及其结构             |
| 邮箱能力           | 支持哪些邮箱协议、相关协议选项                        | 决定可以使用哪些配置和通信功能          |
| SyncManager 描述 | 默认地址、大小、控制设置和用途等                       | 为邮箱和过程数据建立 SM 配置         |
| FMMU 用途        | 输入、输出、邮箱状态等用途描述                        | 帮助分配 FMMU 资源             |
| PDO 描述         | 可用 RxPDO/TxPDO、默认配置、对象条目、位长、名称、关联 SM 等 | 建立过程数据布局和工程变量            |
| PDO 配置限制       | 映射是否固定、支持哪些组合或分配方式等                    | 限制工程工具提供的可选配置            |
| CoE 能力         | 是否支持 SDO Info、PDO 分配配置、PDO 映射配置等能力声明   | 决定如何查询或配置设备              |
| 对象字典描述         | 数据类型、对象索引、名称、子项、访问权限、默认值、PDO 映射属性等，可选  | 展示参数，解释数据，辅助离线配置         |
| 初始化命令          | 特定阶段需要执行的邮箱或 SDO 初始化操作等                | 启动时向从站下发相应配置             |
| DC 工作模式        | 可选同步模式、SYNC0/SYNC1 相关周期或偏移规则、激活参数等     | 为用户提供同步模式选择，并生成配置        |
| EEPROM 配置相关信息  | EEPROM 大小、配置数据等，视描述而定                  | 为相应工具生成或检查 EEPROM 内容提供依据 |

## SII 包含哪些信息
固定头部、Strings、General、FMMU、SyncManager、TxPDO描述、RxPDO描述、DC

| 内容             | 具体包含什么                                                                        | 谁使用、用来做什么              |
| -------------- | ----------------------------------------------------------------------------- | ---------------------- |
| ESC 启动配置       | PDI 控制、ESC 配置、PDI配置、SYNC 初始脉宽、扩展 PDI 配置、站别名、配置区校验                             | ESC 上电自动装载，使硬件具备基本工作条件 |
| 设备身份           | Vendor ID、Product Code、Revision、Serial Number                                 | 主站识别厂商、产品、修订和具体设备      |
| 邮箱位置与大小        | 正常通信时两个方向的邮箱 起始地址和长度；<br>支持时还包括 Bootstrap 邮箱配置<br>（**从站进入 BOOT 时使用的邮箱地址和大小**） | 主站据此建立邮箱通信             |
| 邮箱协议支持         | 是否声明支持 CoE、EoE、SoE、<br>FoE（**通过邮箱传输文件的协议**）                                   | 主站知道可以采用哪些上层协议         |
| EEPROM 自身信息    | 容量、SII 格式版本等                                                                  | 按相应范围和格式读取             |
| 字符串            | 设备名称、分组名称、图像名称等描述字符串                                                          | 给其他描述项提供可引用的文字         |
| General 信息     | 端口物理类型、部分通信能力标志、设备相关属性等                                                       | 主站了解设备基本能力             |
| FMMU 描述        | FMMU 的用途类型，例如输出、输入、邮箱状态等                                                      | 为主站分配映射资源提供依据          |
| SyncManager 描述 | 各 SM 的默认起始地址、长度、控制设置、使能及用途类型                                                  | 主站建立邮箱和过程数据通道          |
| RxPDO、TxPDO 描述 | PDO 索引、关联 SM、条目顺序，<br>条目的对象索引、子索引、位长、数据类型等                                    | 主站了解设备提供的过程数据布局        |
| DC 描述          | 支持的同步运行模式及相关周期、偏移、激活设置等描述                                                     | 主站选择和配置相应同步方式          |
这里要区分两个阶段：
**ESC 上电自动装载的硬件配置**，以及**主站随后读取、用于建立运行配置的设备描述**。
1. SII 中写了“SM0 默认放在什么位置”，不等于 ESC 上电后已经自动完成所有邮箱 SM 配置。
2. 某台从站的输出数据分配到哪个逻辑地址，这个逻辑地址对应哪个 ESC 内部地址，映射多长、从哪一位开始。   这些仍由主站根据整个网络的数据布局计算，再写入 ESC 的 FMMU 配置寄存器。
3. SII 可以列出某个 PDO 使用了哪些对象，但这不等于列出了设备所有参数。
   例如它可能描述 PDO 中含有 `0x6040:00` 和 `0x607A:00`，
   却不提供其他诊断参数、厂商参数的完整说明。

Bootstrap 邮箱配置、FOE：
```
主站读取 SII 中的 Bootstrap 邮箱配置
    ↓
按设备要求配置 BOOT 状态使用的邮箱 SM
    ↓
请求从站进入 BOOT，确认成功
    ↓
通过这些邮箱进行 FoE 文件传输
    ↓
从站的固件更新程序接收文件并处理
```

## ET1100 自动加载的启动配置

以 ET1100 和外部 EEPROM 为例，ESC 退出复位后读取 SII 的 ESC Configuration Area，
检查校验并装载初值。该区域占 EEPROM 字地址 `0x0000～0x0007`，共 8 个 16 位字，即 16 B。

| EEPROM 字地址      | 内容                             | 对应 ESC 字节地址     |
| --------------- | ------------------------------ | --------------- |
| `0x0000` 低字节    | PDI Control，选择数字 IO、SPI、并行微控制器 | `0x0140`        |
| `0x0000` 高字节    | ESC Configuration，设置相关 ESC 功能  | `0x0141`        |
| `0x0001`        | PDI Configuration，设置所选接口的具体选项  | `0x0150～0x0151` |
| `0x0002`        | SYNC 信号脉宽                      | `0x0982～0x0983` |
| `0x0003`        | 扩展 PDI 配置，按支持情况使用              | `0x0152～0x0153` |
| `0x0004`        | 配置站别名                          | `0x0012～0x0013` |
| `0x0005～0x0006` | 保留                             | —               |
| `0x0007`        | 配置区校验信息                        | —               |

EEPROM 表用的是**字地址**，ESC 表用的是**字节地址**。

这里的 SYNC 脉宽不等于 SYNC0 周期；
站别名也不等于主站随后写入的配置站地址。

**PDI Operational**：
是 ESC 的 **DL Status 寄存器 `0x0110`  bit 0**，表示 PDI 是否已具备工作条件

**EEPROM_Loaded**：
是 ET1100 在相应 **PDI 模式、引脚配置**下提供的 硬件状态信号，向外部电路指示 EEPROM 启动配置已成功加载。

```
ET1100 上电、退出复位
    ↓
读取 EEPROM 中的 ESC 启动配置区
    ↓
检查配置并装载 PDI 等初始设置
加载成功，PDI 具备工作条件
    ↓
相应寄存器状态 / EEPROM_Loaded 信号反映结果
    ↓
MCU 按接口要求开始正常访问 ESC
```

主站可从 EtherCAT 侧读取 DL Status；
如果硬件提供并连接了 EEPROM_Loaded，MCU 也可观察该信号。

CANopen 本身就使用对象字典，设备对外提供的 数据和参数 的组织方式
CoE 把 CANopen 对象字典、SDO、PDO 等机制带到 EtherCAT 

**SDO 是访问对象字典的一种服务**


## EEPROM 访问控制

主站和 PDI 侧都可能需要访问 EEPROM，因此要先处理访问所有权，避免双方同时发命令。
读、写和 Reload 还涉及 Busy、错误状态、写使能及保护条件。

EEPROM 写入可能需要毫秒级内部处理时间。
前一笔写入尚未完成时继续操作，可能遇到忙或不应答；
它不能像普通 RAM 一样不检查状态就连续写入。

EEPROM 保存的是启动和描述信息；
运行时的过程数据交换见[PDO](../../通信机制/PDO/PDO.md)，
主站配置工作见[主站配置](../主站配置/主站配置.md)。
