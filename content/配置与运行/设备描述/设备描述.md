# 设备描述

主站要正确配置一台从站，需要知道 设备身份、通信能力、数据布局、同步方式。

## EEPROM、SII 与 ESI

| 名称                              | 所在位置              | 作用          |
| ------------------------------- | ----------------- | ----------- |
| EEPROM                          | 从站上的非易失存储器        | 保存掉电后仍保留的数据 |
| SII：Slave Information Interface | 从站侧，常存放在 EEPROM 中 |             |
| ESI：EtherCAT Slave Information  | 主站工程工具侧的 XML 文件   |             |

在线扫描时，主站读取 SII 身份并与工程配置、ESI 描述匹配；
离线配置时，工具可先根据 ESI 建立设备和数据布局。

身份字段包括 Vendor ID、Product Code 和 Revision。
ESI 可包含对象字典相关描述，但不能假定每份 ESI 都完整列出所有可访问对象。

## SII 包含哪些信息

SII 可以提供 ESC 启动配置、设备身份、邮箱协议及地址长度、SyncManager 和 FMMU 描述，以及 PDO、DC、字符串等分类信息。

这里要区分两个阶段：**ESC 上电自动装载的硬件配置**，以及**主站随后读取、用于建立运行配置的设备描述**。邮箱和 PDO 描述出现在 SII 中，不等于 ESC 上电就把所有 SM、FMMU 和运行状态自动配置完毕。

例如设备实际实现了 CoE，但 SII 未正确声明，依赖自动识别的主站可能不会启用所需的 CoE 配置流程。描述文件、SII 内容和从站程序需要一致。

## ET1100 自动加载的启动配置

以 ET1100 和外部 EEPROM 为例，ESC 退出复位后读取 SII 的 ESC Configuration Area，检查校验并装载初值。该区域占 EEPROM 字地址 `0x0000～0x0007`，共 8 个 16 位字，即 16 B。

| EEPROM 字地址 | 内容 | 对应 ESC 字节地址 |
| --- | --- | --- |
| `0x0000` 低字节 | PDI Control | `0x0140` |
| `0x0000` 高字节 | ESC Configuration | `0x0141` |
| `0x0001` | PDI Configuration | `0x0150～0x0151` |
| `0x0002` | SYNC 信号脉宽 | `0x0982～0x0983` |
| `0x0003` | 扩展 PDI 配置，按支持情况使用 | `0x0152～0x0153` |
| `0x0004` | 配置站别名 | `0x0012～0x0013` |
| `0x0005～0x0006` | 保留 | — |
| `0x0007` | 配置区校验信息 | — |

EEPROM 表用的是**字地址**，ESC 表用的是**字节地址**。例如 EEPROM 一个地址保存 2 B，不能直接与 ESC 地址一一比较。

启动加载决定 MCU 使用什么 PDI，以及有关 ESC 功能和引脚选项。PDI Operational 和接口提供的 EEPROM_Loaded 等状态可用于判断基础初始化。邮箱、PDO 与同步运行参数仍需后续配置。

这里的 SYNC 脉宽不等于 SYNC0 周期；站别名也不等于主站随后写入的配置站地址。

## EEPROM 访问控制

主站和 PDI 侧都可能需要访问 EEPROM，因此要先处理访问所有权，避免双方同时发命令。读、写和 Reload 还涉及 Busy、错误状态、写使能及保护条件。

EEPROM 写入可能需要毫秒级内部处理时间。前一笔写入尚未完成时继续操作，可能遇到忙或不应答；它不能像普通 RAM 一样不检查状态就连续写入。

EEPROM 保存的是启动和描述信息；运行时的过程数据交换见[PDO](../../通信机制/PDO/PDO.md)，主站配置工作见[主站配置](../主站配置/主站配置.md)。
