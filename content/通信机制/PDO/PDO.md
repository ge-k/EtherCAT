# PDO

**PDO（Process Data Object，过程数据对象）** 描述需要交换的过程数据，
例如伺服目标位置、实际位置、控制字、状态字和 IO 位。

## 方向从从站看

| 名称    | 从站视角 | 主站视角 | 例子       |
| ----- | ---- | ---- | -------- |
| RxPDO | 从站接收 | 主站输出 | 目标位置、控制字 |
| TxPDO | 从站发送 | 主站输入 | 实际位置、状态字 |

## 映射与分配

以支持 CoE 的设备为例，对象字典按 Index 和 SubIndex 标识参数。
PDO 分配，确定使用哪些 PDO。
PDO 映射，确定 哪些对象的哪些位 进入过程数据、按什么顺序排列、占多长。

常见分配对象 RxPDO `0x1C12`、TxPDO `0x1C13`
常见映射对象 RxPDO `0x1600` 起、TxPDO `0x1A00` 起。

主站可以通过 [SDO](../邮箱与CoE/邮箱与CoE.md) 修改设备允许配置的映射；默认映射已满足要求时可以直接沿用。

## 周期数据怎样到应用

```text
主站按 PDO 布局准备目标值
→ 通过 LWR/LRW 等过程数据访问发送
→ FMMU 将逻辑地址映射到从站 RAM
→ SM 管理网络侧和应用侧的数据交接
→ MCU 经 PDI 取得完整目标值
```

周期过程数据通常不重复携带每个对象的 Index/SubIndex，而按预先约定的偏移解释字节。
因此，主站与从站对映射的理解必须一致。

PDO 通道没有 SDO 那样逐次返回应用命令应答，但底层仍有 [WKC](../../诊断与调试/WKC/WKC.md)用于检查访问参与情况。

## PDO 与 SDO 的分工

SDO 采用请求—响应方式访问对象字典，常用于参数配置。
PDO 通道常用于周期性、实时交换。

数据传到 ESC、应用采用目标值、传感器采样反馈，是不同的时刻。
见[启动与周期运行](../../配置与运行/启动与周期运行/启动与周期运行.md)。
