# 寻址与命令

EtherCAT Datagram 的 Address 字段有 4 B，含义由 Cmd 决定。先看命令，再解释地址，可以避免把广播当成单站访问，或把逻辑地址拆成站地址。

## 按位置与按配置地址

**自动增量寻址**用于按报文经过各从站 EPU 的顺序寻找设备。ADP 是报文中的位置计数，每经过一站递增，收到 ADP 为 0 的目标站处理相应访问。

从主站发出时，`0` 对应第一站，`-1`（16 位表示为 `0xFFFF`）对应第二站，`-2` 对应第三站。这里的负数在报文中，不是各从站预先保存了自己的负地址。

主站可以用这种方式逐站读取信息，并写入配置站地址。以 SOEM 的常见初始化流程为例，先 BRD 读取所有从站都支持的 ESC 寄存器，通过 WKC 得到参与站数，再按位置逐站访问。

**配置地址寻址**使用主站分配的站地址。配置站地址位于 ESC `0x0010～0x0011`；`0x0012～0x0013` 是站别名，不能混为一谈。

```text
FPRD，ADP=0x0001，ADO=0x0300，Len=4
→ 读取配置地址为 1 的从站内部 0x0300 起的 4 个字节
```

这两类寻址把 Address 分成 16 位 ADP 和 16 位 ADO。ADP 决定按位置或配置地址找谁，ADO 是该 ESC 内部的字节地址。

## 逻辑寻址

逻辑寻址把完整 32 位 Address 作为逻辑地址，最多表示 4 GB 逻辑地址空间。它是统一的网络数据视图，并不代表主站或某台 ESC 实际拥有 4 GB RAM。

```text
逻辑 0x0000～0x0001 → 从站 A 的 2 字节输入
逻辑 0x0002～0x0003 → 从站 B 的 2 字节输入
逻辑 0x0004～0x0005 → 从站 C 的 2 字节输入

LRD，Addr=0x0000，Len=6
→ 在一条 Datagram 中读回三站数据
```

各站的 [FMMU](../FMMU/FMMU.md) 保存逻辑地址与本站内部地址的对应关系。Datagram 经过时，只有命中的映射参与处理。

## 广播

广播访问各站相同的 ADO。BRD 的读结果与 Datagram 现有 Data **按位 OR** 合并，因此主站通常先把读数据区清零。

例如读取 AL Status：各站均为 OP（`0x0008`）时，状态位合并仍为 `0x0008`；其中一站为 SAFE-OP（`0x0004`）而另有 OP 从站时，会得到 `0x000C`。这个合并值不是某台从站实际处于 `0x000C` 状态。

广播适合整体检测，不能从合并值直接恢复每台从站的数据。需要定位时，应逐站读取。

## 命令速查

| 访问方式 | 读 | 写 | 读写 |
| --- | --- | --- | --- |
| 自动增量 | APRD | APWR | APRW |
| 配置地址 | FPRD | FPWR | FPRW |
| 广播 | BRD | BWR | BRW |
| 逻辑地址 | LRD | LWR | LRW |

读写命令可以同时交换原有数据与待写数据，实际访问效果还取决于权限、映射和 SM 状态。工作计数规则见 [WKC](../../诊断与调试/WKC/WKC.md)。

## ARMW 与 FRMW

Read Multiple Write 用一条 Datagram 从选定从站读取数据，并向其他符合处理条件的从站写入数据。ARMW 以自动增量位置选读站，FRMW 以配置站地址选读站。

常见用途是分发 DC 参考时钟：

```text
FRMW，ADP=0x0001，ADO=0x0910，Len=8
参考站把自己的 System Time 放入 Data
→ 后续 DC 从站把这个参考时间作为同步输入
```

访问 `0x0910` 的同步写入具有时钟控制语义，并非简单用收到的值覆盖本站当前时间。其工作方式见 [DC 时钟](../../时钟同步/DC时钟/DC时钟.md)。
