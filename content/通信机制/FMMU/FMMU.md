# FMMU

**FMMU（Fieldbus Memory Management Unit）** 是 ESC 内部的 地址映射 硬件。
它把 EtherCAT 逻辑地址，映射到本从站的 寄存器 或 RAM 地址，
使主站可以用统一地址范围，访问分散在多个从站的数据。

## 保存规则，运行时匹配

启动时，主站 把映射规则写入 ESC 的 FMMU 配置区。
运行时，带逻辑地址的 Datagram 经过，各 FMMU 判断本次访问是否与自身映射相交。

一条映射主要包含：

| 配置         | 含义              |
| ---------- | --------------- |
| 逻辑起始地址、长度  | 覆盖哪些逻辑字节        |
| 逻辑起始位、结束位  | 首尾字节中哪些位属于映射    |
| 物理起始地址、起始位 | 对应到本 ESC 内部哪个位置 |
| 读/写类型      | 网络侧 读取或写入 哪些数据  |
| 激活         | 当前是否启用该映射       |

ET1100 的 FMMU 配置区从 `0x0600` 开始，FMMU 存的是映射规则。

## 一个配置块怎样解析

从`0x0600`起，每个FMMU占16 B：

```text
逻辑起点4B | 逻辑长度2B | 逻辑起始位1B | 逻辑结束位1B
物理起点2B | 物理起始位1B | 类型1B | 激活1B | 保留3B
```

类型bit0允许读映射、bit1允许写映射，因此类型1是读、2是写。激活bit0=1后映射才参与匹配。不要把它与SM Control的方向位编码混用。

## 两台设备怎样拼成33字节

以下采用上电报文笔记中的配置示例：站1每个方向32 B，站2每个方向1 B。两台各有独立的ESC地址空间，再由FMMU接入同一份网络逻辑布局。

| 访问方向 | 设备 | 逻辑范围 | 本站RAM范围 | 长度 |
| --- | --- | --- | --- | --- |
| 主站读输入 | 站1 | `0x00～0x1F` | `0x1860～0x187F` | 32 B |
| 主站读输入 | 站2 | `0x20` | `0x1400` | 1 B |
| 主站写输出 | 站1 | `0x21～0x40` | `0x1800～0x181F` | 32 B |
| 主站写输出 | 站2 | `0x41` | `0x1100` | 1 B |

一次`LWR，起点0x21，长度33 B`的Data第0～31字节由站1处理，第32字节由站2处理；LRD从0x00读33 B时，各站分别填入对应输入。每站只处理自己的范围，MCU不负责把整份33 B转发给下一站。

站1的32 B三缓冲输出窗口为`0x1800～0x181F`，三份占用到`0x185F`，输入窗口从`0x1860`开始，因此访问窗口长度与实际RAM占用不能混淆。站2的1 B配置要按它的ESC实现理解，不能照搬成ET1100的正常三缓冲。

## 一个跨字节的位映射

假设有以下写映射，所选 RAM 已按设备需要配置：

```text
逻辑起始地址：0x00014711
逻辑长度：2 字节

逻辑起始位：3
逻辑结束位：0

ESC 内部起始地址：0x1100
ESC 内部起始位：1

类型：写映射
激活：1
```

这里的 2 字节表示逻辑地址跨度，不代表传输了完整 16 位：

```text
0x14711 的 bit3～bit7：5 位
0x14712 的 bit0：     1 位
合计：6 位
```

这 6 位依次映射到 ESC `0x1100` 的 bit1～bit6。
位映射使 多个设备的少量 IO 可以紧凑排列，而不必每个信号占一个完整字节。

## FMMU、SM 与 PDO 不同

| 概念                                           | 回答的问题               |
| -------------------------------------------- | ------------------- |
| [PDO](../PDO/PDO.md)                         | 数据有哪些业务含义，顺序和位长是什么  |
| FMMU                                         | 逻辑地址对应 本站 哪个地址与位范围  |
| [SyncManager](../SyncManager/基本原理/基本原理.md) | 网络侧和应用侧，怎样一致地交换这段数据 |
| DPRAM                                        | 数据实际存储在哪里           |

FMMU 不是所有 ESC 访问的必经步骤。
FPRD/FPWR 等直接按 站地址 访问，不需要先经过逻辑映射。
