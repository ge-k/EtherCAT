# FMMU

**FMMU（Fieldbus Memory Management Unit）** 是 ESC 内部的地址映射硬件。它把 EtherCAT 逻辑地址映射到本从站的寄存器或 RAM 地址，使主站可以用统一地址范围访问分散在多个从站的数据。

## 保存规则，运行时匹配

启动时，主站把映射规则写入 ESC 的 FMMU 配置区；运行时，带逻辑地址的 Datagram 经过，各 FMMU 判断本次访问是否与自身映射相交。

一条映射主要包含：

| 配置 | 含义 |
| --- | --- |
| 逻辑起始地址、长度 | 覆盖哪些逻辑字节 |
| 逻辑起始位、结束位 | 首尾字节中哪些位属于映射 |
| 物理起始地址、起始位 | 对应到本 ESC 内部哪个位置 |
| 读/写类型 | 网络侧读取或写入哪些数据 |
| 激活 | 当前是否启用该映射 |

ET1100 的 FMMU 配置区从 `0x0600` 开始。FMMU 存的是映射规则，不存业务数据，也不是把主站的整片过程映像复制到每台从站。

## 一个跨字节的位映射

假设有以下写映射，所选 RAM 已按设备需要配置：

```text
逻辑起始地址：0x00014711
逻辑长度：2 字节
逻辑起始位：3
逻辑结束位：0
ESC 内部起始地址：0x1100
ESC 内部起始位：1
类型：写映射
激活：1
```

这里的 2 字节表示逻辑地址跨度，不代表传输了完整 16 位：

```text
0x14711 的 bit3～bit7：5 位
0x14712 的 bit0：     1 位
合计：6 位
```

这 6 位依次映射到 ESC `0x1100` 的 bit1～bit6。位映射使多个设备的少量 IO 可以紧凑排列，而不必每个信号占一个完整字节。

## FMMU、SM 与 PDO 不同

| 概念 | 回答的问题 |
| --- | --- |
| [PDO](../PDO/PDO.md) | 数据有哪些业务含义，顺序和位长是什么 |
| FMMU | 逻辑地址对应本站哪个地址与位范围 |
| [SyncManager](../SyncManager/SyncManager.md) | 网络侧和应用侧怎样一致地交换这段数据 |
| DPRAM | 数据实际存储在哪里 |

FMMU 不是所有 ESC 访问的必经步骤。FPRD/FPWR 等直接按站地址和内部地址访问，不需要先经过逻辑映射。

没有匹配的 FMMU，或映射方向与命令不符时，本站不会仅凭“报文经过了”就完成该逻辑数据访问。主站可通过预期 WKC 与实际 WKC 的比较发现参与情况异常。
